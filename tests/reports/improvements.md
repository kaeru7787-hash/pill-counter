# 初期改善記録

対象は付属の合成画像17枚。同じセットで改善しているため、汎化性能・臨床的精度は評価していません。

|原因分類|観測した問題|変更|
|---|---|---|
|False Negative|90個の独立錠剤で検出0。複数ケースで種の数画素だけが残った|OpenCV watershedが勾配を使う点を踏まえて地形を修正。1画素の種を距離に応じたコアへ変更|
|Merged pills|3個の接触で中心の偽ピーク1個を採用|3方向の独立ローブに支持がある場合、合流点のピークを抑制|
|Split pill|上記改善でカプセル12個が14個へ悪化|距離の尾根でピークを統合する閾値を再調整。全ケースを再評価して回帰を解消|
|Background|トレーの囲み枠の外輪郭だけを抽出し、内側を塗りつぶした|CCOMP階層、穴の面積控除、囲み枠除外、元マスクとの積で穴を保持|
|Bag artifact / Reflection|袋の細い線が錠剤と接続し、形状フィルターで錠剤ごと除外|画像内の候補の距離分布から線の除去スケールを算出|
|False Positive|微小な点状ノイズ|open処理と面積分布に対する相対除外|

比較数値は `baseline.json` / `latest.json` / `latest.md` に保存。

## 残る課題

- 実写が0枚。錠剤種・照明・背景・iPhone機種・反射の強さを分けた未使用データで評価する。
- 丸い反射、袋のロゴ、似た色の背景などは古典CVだけでは意味的識別できない。
- 遠近差や極端な大小混在では、相対面積除外が小さい錠剤を除外する可能性がある。
- 完全な重なりでは写真に見えない錠剤を数えられない。
- CV3条件の誤りには相関がある。独立した学習済みAIの導入と検証が必要。
- 誤差0でも、過検出と未検出の相殺を位置アノテーションで調べる必要がある。

## 実写データの推奨分割

同じ撮影シーンの類似画像が改善用と評価用に跨がらないよう分ける。最終評価用セットを閾値調整には使わない。黒トレー、机、袋、接触、色・剤形混在を別集計する。評価失敗時に「要確認」を正しく出せた割合も、完全一致率とは別に追跡する。
