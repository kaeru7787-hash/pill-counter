# 初期改善記録

対象は付属の合成画像17枚。同じセットで改善しているため、汎化性能・臨床的精度は評価していません。

| 原因分類                  | 観測した問題                                              | 変更                                                                                  |
| ------------------------- | --------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| False Negative            | 90個の独立錠剤で検出0。複数ケースで種の数画素だけが残った | OpenCV watershedが勾配を使う点を踏まえて地形を修正。1画素の種を距離に応じたコアへ変更 |
| Merged pills              | 3個の接触で中心の偽ピーク1個を採用                        | 3方向の独立ローブに支持がある場合、合流点のピークを抑制                               |
| Split pill                | 上記改善でカプセル12個が14個へ悪化                        | 距離の尾根でピークを統合する閾値を再調整。全ケースを再評価して回帰を解消              |
| Background                | トレーの囲み枠の外輪郭だけを抽出し、内側を塗りつぶした    | CCOMP階層、穴の面積控除、囲み枠除外、元マスクとの積で穴を保持                         |
| Bag artifact / Reflection | 袋の細い線が錠剤と接続し、形状フィルターで錠剤ごと除外    | 画像内の候補の距離分布から線の除去スケールを算出                                      |
| False Positive            | 微小な点状ノイズ                                          | open処理と面積分布に対する相対除外                                                    |

比較数値は `baseline.json` / `latest.json` / `latest.md` に保存。

## 残る課題

- 改善に使用した実写が5枚のみ。錠剤種・照明・背景・iPhone機種・反射の強さを分けた未使用データで評価する。
- 丸い反射、袋のロゴ、似た色の背景などは古典CVだけでは意味的識別できない。
- 遠近差や極端な大小混在では、相対面積除外が小さい錠剤を除外する可能性がある。
- 完全な重なりでは写真に見えない錠剤を数えられない。
- CV3条件の誤りには相関がある。独立した学習済みAIの導入と検証が必要。
- 誤差0でも、過検出と未検出の相殺を位置アノテーションで調べる必要がある。

## 実写データの推奨分割

同じ撮影シーンの類似画像が改善用と評価用に跨がらないよう分ける。最終評価用セットを閾値調整には使わない。黒トレー、机、袋、接触、色・剤形混在を別集計する。評価失敗時に「要確認」を正しく出せた割合も、完全一致率とは別に追跡する。

## v0.2 実写の過少検出を修正

ユーザーの公開版スクリーンショットは33個（ピンセット1個を含む）。同じ元写真を旧コード・Nodeのデコードで再実行すると27個でした。33と27は環境が違う結果なので同一測定として比較しません。旧Node結果は`real-before.json`に保存しています。

| 原因分類                      | 根本原因                                                                               | 変更                                                                                                |
| ----------------------------- | -------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| Merged pills / False Negative | 分離前に大きな接触blobを除外。大面積に偏った代表サイズ、尾根ピーク抑制が密集部を消した | 分離を先に実行。単独候補の半径分布によるサイズ推定、距離ピークと円弧の補助種、Watershed後の形状検査 |
| Background / False Positive   | 自動ROIが初期OFF。画像の外周背景推定と矩形ROIが机・金属を含んだ                        | 自動範囲ON、黒トレーの輪郭支持マスクで外側を除外                                                    |
| Reflection / Split pill       | トレー反射の細い接続部が分割輪郭を引き延ばした                                         | 観測した種の半径に合わせて分割領域を制限、形状で反射を除外                                          |
| Runtime                       | WASMメモリ拡張後に古いTypedArray参照を使うと種の領域が消える                           | 輪郭抽出の各反復で最新の画素配列を取得                                                              |

| 評価                           |        改修前 |           改修後 |
| ------------------------------ | ------------: | ---------------: |
| 提供実写（旧/新Node）          |   27、誤差-63 |        90、誤差0 |
| 提供実写の位置評価             |        未集計 | TP90 / FP0 / FN0 |
| 既存合成17枚                   | 17/17完全一致 |    17/17完全一致 |
| 同じ18枚のExact Count Accuracy |         17/18 |            18/18 |
| 同じ18枚のMAE                  |           3.5 |                0 |
| 同じ18枚の±1 Count Accuracy    |         17/18 |            18/18 |

新コードは画像内容だけで候補を生成し、90を目標にする補正係数や座標の埋め込みを使用しません。正解データはテストだけが読み込みます。参照実写は改善用データであり、独立した検証セットではありません。

## v0.3 着色錠剤と袋の誤検出

ユーザーのiPhone画面では丸形12錠が3または5、長円形36錠が2でした。v0.2をNodeで長辺2048px以下・袋モードとして再実行すると66と59でした（`19-bag-round-before.json`、`20-bag-oblong-before.json`）。ROI・モード・デコード条件が異なるため、スクリーンショットの数字との同一条件比較ではありません。

- Background / Reflection / Bag artifact：明度・背景色推定が袋の反射・机・影を広い前景に結合。彩度Otsu、色相の集中度、形状内部の色被覆率で前景候補を限定。
- Merged pills：大きな接触領域を距離ピークだけで分離できない。観測した半径を基準とする複数角度・複数サイズの形状照合を追加し、支持された種から元解像度Watershedを実行。
- Split pill：長円形の割線・袋の印字による分断。代表面積・長軸・凸包に対する相対条件で小断片を統合。
- Regression：着色経路を多色カプセルに適用すると12から6へ悪化。色相が混在する場合は汎用経路に戻し、全20画像を再検証。

| 同じ元写真・Node袋モード | v0.2 | v0.3 | 位置評価         |
| ------------------------ | ---: | ---: | ---------------- |
| 丸形（正解12）           |   66 |   12 | TP12 / FP0 / FN0 |
| 長円形（正解36）         |   59 |   36 | TP36 / FP0 / FN0 |

既存18枚は全て正解を維持。実写3枚+合成17枚のExact Count Accuracyは18/20から20/20、MAEは3.85から0、±1 Count Accuracyは18/20から20/20です。正解は推論に渡さず、ファイル名、印字、期待個数から候補を補正しません。

黄色錠剤の黒トレー元写真が同名JPEGへ差し替えられていたため、画像内容を確認して別名のロスレスPNGに保存。12錠と36錠の両方を正しく検出し、位置評価もFP0・FN0でした。青みのあるトレーでは彩度だけでは背景優勢となるため、明度Otsuと明度範囲を使って明るい錠剤を支持するマスクを作り、彩度を再評価しています。5枚の実写と17枚の合成の22枚すべてで個数が一致しました。形状探索は長辺960pxまで、最終分割は解析解像度で行います。同色同寸法向けの補助経路であり、色・サイズ・剤形混在や反射の強い未知画像への性能は未確立です。
